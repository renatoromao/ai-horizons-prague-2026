## What this covers

Microsoft Copilot (Microsoft 365 Copilot) is sold as an **add-on** license: to assign it to a
user, that user must already hold an eligible base Microsoft 365, Office 365, Microsoft Teams,
Exchange, SharePoint, OneDrive, Planner/Project, or Visio subscription plan. Eligible base plans
span several categories: business plans, enterprise-oriented Microsoft 365/Office 365/Teams
plans, US Government Community Cloud (GCC, GCC-High, DoD) plans, and education plans available
through education-specific licensing programs. The exact list of eligible base plan names is
maintained on the official page and changes over time — it is not reproduced here.

## Copilot Chat vs. the Copilot add-on

Separate from the paid add-on, **Copilot Chat** is an AI prompt/response experience automatically
included for organizations with an eligible Microsoft 365 subscription, at no extra cost. It has
two modes: a web-based mode that draws on general web results, and a work-based mode that draws
on content the signed-in user's account can access — the latter requires the paid Copilot add-on
license. Copilot Chat eligibility and the underlying qualifying subscriptions are themselves
maintained on a separate, linked reference page.

## License assignment

Once an organization has acquired Copilot licenses, an admin assigns them to individual users
through the Microsoft 365 admin center (the same mechanism used for any other Microsoft 365
license), or via the guided Microsoft Copilot setup guide, which walks through the rollout phase
including license assignment.

## What this source does not do

This snapshot deliberately does not enumerate the specific base-plan SKU names as an exhaustive,
factual list, and it never states a price. Base-plan eligibility lists and pricing change; the
agent should retrieve the current list from the official page (or the linked Microsoft Copilot
service description guide) and cite it rather than assert plan names from memory.

For current prices/limits, see: https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-licensing
