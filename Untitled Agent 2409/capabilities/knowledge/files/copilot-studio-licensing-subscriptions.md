# Name: Copilot Studio Licensing Subscriptions

<!-- Copilot Studio licensing paths: trial, standalone subscription, and Teams-plan entitlement (conceptual comparison, not current prices/quotas) -->

## What this covers

This snapshot describes the different ways an organization or individual can get access to
Copilot Studio, at a conceptual level, and how they differ in capability — not what each option
costs.

## Access paths

- **Individual trial** — anyone can sign up for a free Copilot Studio trial using a work or
  school email address. The trial allows building and testing agents in the test chat panel, but
  does not allow publishing. The trial period can be extended once it expires, and an agent built
  during a trial keeps working for a further grace period after the trial itself ends, so access
  does not disappear immediately.
- **Standalone Copilot Studio subscription** — a dedicated subscription, assigned like any other
  Microsoft 365 admin-center license, that unlocks the full range of Copilot Studio capabilities
  (all supported channels, premium connectors, generative orchestration, custom topic authoring
  with AI assistance, Bot Framework skill extensibility, live-agent hand-off, and more).
- **Copilot Studio for Microsoft Teams plan** — a narrower capability set bundled into select
  Microsoft 365 subscriptions with Power Platform and Teams capabilities. It supports classic
  orchestration and publishing to Teams using Dataverse for Teams or Power Automate–connected
  data sources, but excludes several capabilities that require the standalone subscription (for
  example generative orchestration, premium connectors, and Bot Framework skill usage). This plan
  is not available in US Government (GCC, GCC High, DoD) or certain education/subscription SKUs.
- **Bundled entitlements** — some Copilot Studio capability is also included as an entitlement
  inside certain Dynamics 365 Customer Service add-ons (Digital Messaging and Chat), separate from
  the two paths above.

## Upgrading

An organization can start on the Teams plan and later upgrade to the standalone subscription
without losing the existing agent or environment — the same agent keeps working, and the
capabilities gated behind the standalone subscription become available once the upgrade lands.

## What this source does not do

This snapshot never states specific prices, Copilot Credit volumes, or quota/limit numbers for
any of these paths — those are maintained on the official Copilot Studio Licensing Guide and the
Copilot Studio Quotas and Limits page, which the agent should retrieve and cite instead of
guessing.

For current prices/limits, see: https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-licensing-subscriptions
